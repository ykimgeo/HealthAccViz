# HealthAccViz

**Same City, Different Answers: Comparing Hospital Accessibility in Mecklenburg County**

An interactive geovisualization for the 2026 GIS Day AI Interactive GeoVisualization Competition. It computes four hospital-accessibility measures for the 305 Census tracts of Mecklenburg County, NC, and lets you compare how the result changes with the measure, the distance basis, the travel impedance, and the distance decay function.

- Live dashboard: <https://ykimgeo.github.io/HealthAccViz/healthcare.html>
- Author: Yunsik Kim, PhD Student in Geography, UNC Charlotte

## What the dashboard does

| Setting | Options |
|---|---|
| Method | Closest facility, Container, Gravity, 2SFCA (Two-Step Floating Catchment Area) |
| Distance basis | Euclidean, road network |
| Travel impedance | travel distance, travel time |
| Distance decay (Gravity, 2SFCA) | Binary, negative exponential, Gaussian, with sliders for the threshold d0 and the coefficient beta |

- **Map**: tracts colored by the applied measure (darker green = better access), hospitals sized by bed count, five selectable basemaps, a scale bar, and a collapsible legend.
- **Summary**: population-weighted mean, median, and share of residents within cutoffs.
- **Selection**: click a tract (its value and contributing hospitals) or a hospital (the tracts it serves).
- **Charts**: the accessibility score against five tract indicators (population, population density, share aged 65+, median age, household income) as z-scores, with Pearson and Spearman correlations, marginal histograms, a 3x3 bivariate color legend, and hover linking between chart and map.
- **Quick Tour** (first visit, and the "?" button) and a **Methods** tab with data, formulas, interpretation, limitations, references, and a statement of AI use.

The formulas, data sources, and limitations are written in the Methods tab of the dashboard; read that first.

## Study area and data

Census tracts are the unit of analysis. Only the 305 Mecklenburg County tracts are drawn and summarized. All 752 tracts of the 14 counties of the Carolinas Regional Explorer area (11 in NC, 3 in SC) are used as demand and route origins, and all hospitals in those counties are supply candidates, to reduce the edge effect at the county line.

| Data | Source | Files |
|---|---|---|
| Tract population and indicators (2024, ACS 5-year based) | Carolinas Regional Explorer, UNC Charlotte Urban Institute | `data/raw/cre/*.json` |
| Block-group population (B01001, NC and SC) | American Community Survey | `data/raw/cre/acs5-*-bg-b01001.json` |
| Tract and block-group boundaries, internal points (2024) | U.S. Census Bureau TIGER/Line | `data/raw/cre/tl_2024_*.parquet` (Git LFS) |
| Hospitals | HIFLD Next | `data/raw/hospitals-3-geojson.geojson` |
| Road network | OpenStreetMap (Geofabrik NC and SC extracts), contributors, ODbL | downloaded when building the OD matrix |

The files `data/raw/Age of Residents.geojson`, `Household Income.geojson`, `Population - Older Adult.geojson`, and `Population Density.geojson` come from an earlier neighborhood-profile-area version and are not used.

## Repository layout

```
healthcare.html            the page (dashboard, Methods tab, Quick Tour dialog)
css/style.css              styles
js/access.js               accessibility measures (pure functions, no DOM)
js/stats.js                correlation statistics (pure functions)
js/main.js                 map, panels, charts, selection
js/tour.js                 Quick Tour
js/math.js                 renders the TeX in the Methods tab (KaTeX)
img/tour/                  screenshots shown in the Quick Tour
data/input/                files the page loads (generated by the tools below)
data/raw/                  original downloads
tools/prepare_input.py     raw data -> data/input
tools/build_od_matrix.py   routing -> data/input/od_matrix.csv
environment.yml            conda environment for the OD build
```

The site is static HTML, CSS, and JavaScript. Leaflet 1.9.4 and KaTeX 0.16.11 are loaded from CDNs, and basemap tiles come from Esri and OpenStreetMap, so an internet connection is needed.

## Run locally

```bash
python3 -m http.server 8000
```

Open <http://localhost:8000/healthcare.html>.

## Rebuild the data

The committed `data/input/` files are enough to run the page. To regenerate them:

```bash
python3 -I tools/prepare_input.py
```

This needs pandas, geopandas, pyarrow, and shapely 2.1 or newer. It writes the Mecklenburg tract polygons, the tract table with population-weighted centroids, the hospital layer, and a metadata file with QA numbers. The TIGER `.parquet` files are stored with Git LFS (see `.gitattributes`), so run `git lfs pull` after cloning.

The OD matrix (752 tracts x 40 hospitals = 30,080 pairs) is computed with r5py and needs Java:

```bash
conda env create -f environment.yml
conda activate healthaccviz-od
python tools/build_od_matrix.py --limit-tract 5   # smoke test
python tools/build_od_matrix.py                   # full run
python tools/build_od_matrix.py --repair          # re-route origins that came back without a route
```

Travel times are car free-flow times from OSM speeds, rounded to whole minutes by r5py. Traffic is not modeled. The run downloads the NC and SC OSM extracts from Geofabrik and records their dates and checksums in `data/input/od_matrix.meta.json`.
